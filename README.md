# 2026 UROP — GTX-A 광역버스 수요 분석

GTX-A 개통 전후 경기 북부 광역버스 이용량을 비교하고, GTX-A와 경합할 가능성이 있는 광역버스 노선을 분석하기 위한 연구 코드 저장소입니다.

## 연구 대상

- 운정중앙역 — 파주시
- 킨텍스역 — 고양시 일산서구
- 대곡역 — 고양시 덕양구

경기도 버스 노선·정류장 자료에서 광역버스 유형, GTX-A 대상지역 경유, 서울행 조건을 차례로 적용해 후보 노선을 선정합니다.

## 작업 흐름

```text
경기도 버스 노선·정류장 조회
        ↓
GTX-A 연계 서울행 광역버스 후보 선정
        ↓
STCIS 노선번호 → 노선 ID 매핑
        ↓
교통카드 수요 데이터 조회
        ↓
STCIS 정류장명·순서 매핑
        ↓
국토부 정류장 위치정보로 좌표 매핑
        ↓
누락 정류장 ID·ARS 보정
        ↓
노선별 수요 집계 및 GTX-A 전후 비교
```

## 데이터 현황

비교 기준일은 2024-10-17과 2025-10-16입니다. 교통카드 데이터는 경기도 승차(`41`)·서울 하차(`11`) 조건으로 조회합니다.

| 파일 | 내용 |
|---|---|
| `gtx_a_transport_card_20241017_raw.csv` | 2024-10-17 원본 수요 데이터 |
| `gtx_a_transport_card_20241017_raw_with_coords_api_filled.csv` | 2024년 데이터와 2024년 추가 노선을 컬럼 통일 후 결합한 파일 |
| `gtx_a_transport_card_20241017_raw_extra_3routes_with_coords.csv` | 2024년 추가 노선 데이터 |
| `gtx_a_transport_card_20251016_raw_with_coords.csv` | 2025-10-16 좌표 포함 데이터 |

현재 확인된 노선 수는 다음과 같습니다.

- 2024년 통합 파일: 24개 노선
  - 기존 21개 노선 + 9030·9030-1·M7111
- 2025년 좌표 포함 파일: 25개 노선
- 2024년 통합 파일과 2025년 파일 모두 승차·하차 정류장명 빈칸 없음

2024년 추가 노선의 과거 노선 ID는 다음과 같습니다.

| 노선 | 과거 노선 ID |
|---|---|
| 2200 | `41091008` |
| 9030 | `41091013` |
| 9030-1 | `41091017` |
| M7111 | `41091900` |

## 누락 정류장 좌표 보완 절차

정류장 ID는 노선·연도별로 다를 수 있으므로 정류장명만으로 좌표를 입력하지 않고 다음 절차로 검증합니다.

1. 좌표가 누락된 정류장의 노선번호, 정류장 ID, 정류장명을 확인합니다.
2. 카카오맵 또는 지자체 버스 정류장 안내에서 해당 정류장의 ARS 번호를 확인합니다.
3. STCIS 정류장 API에서 시도코드와 ARS 번호로 STCIS 정류장 ID, 정류장명, ARS 번호를 조회합니다.
4. 조회 결과를 교통카드 데이터와 대조합니다. 동일한 정류장명이라도 방향별·위치별로 ARS 번호가 다를 수 있으므로 인접 정류장이나 반대편 정류장의 좌표를 사용하지 않습니다.
5. 국토교통부 전국 버스정류장 위치정보 CSV에서 ARS 번호, 지역코드, 정류장 ID가 일치하는 행을 확인하고 위도·경도를 가져옵니다.
6. 교통카드 데이터에 좌표를 입력합니다.
   - 승차 정류장: `승차위도`, `승차경도`
   - 하차 정류장: `하차위도`, `하차경도`
7. 입력 후 정류장 ID·정류장명·노선 방향의 일치 여부와 승차·하차 좌표 누락 행을 다시 검증합니다. 2024년과 2025년 파일은 각각 별도로 확인합니다.

## API 키

API 키는 코드에 직접 기록하지 않고 `.env` 또는 노트북 입력란을 사용합니다. `.env`는 Git에 업로드하지 않습니다.

필요한 API는 경기도 버스 정보 API, STCIS 노선·정류장 API, 경기도 교통카드 합성데이터 API입니다.
