# data/ — 데이터 넣는 곳

## GitHub에서 최종모형만 실행하는 경우

최종 Poisson QMLE와 음이항 NB2 노트북에 필요한 공개 가능한 집계자료는 저장소에 포함되어 있다.

- `processed/10_셀노선별_종일승차인원.csv`: 셀×노선별 2024·2025 종일 승차인원
- `processed/09_회귀분석_격자통합데이터.csv`: 격자별 분석 변수
- `processed/05_GTX_경쟁목적지비율_종일_셀노선.csv`: 2024년 종일 셀×노선별 GTX 경쟁 목적지 비율
- `processed/11_20~50대인구변화_2024_2025_250m격자.csv`: 2024→2025년 20~50대 인구 변화량
- `processed/`: GTX 보행시간, IC 도로거리, 인구·건축물 및 공급구조 유지 셀 자료

따라서 `analysis/11-1`, `11-2`, `11-3`은 원시 교통카드 자료 없이 실행할 수 있다.

아래 원자료 배치는 전처리 과정 전체를 처음부터 다시 수행할 때만 필요하다.

`raw/` 원자료는 용량이 크므로 **Git과 전달용 zip에서 제외**한다. 분석에 필요한 `processed/` 집계자료는 저장소와 전달용 zip에 포함한다.
아래 표대로 파일을 넣으면 노트북이 그대로 돌아간다. 경로는 `../config.py`에 정의되어 있다.

## 새 데이터가 생기면

- **교통카드 날짜 추가**: `raw/transport_card/`에 같은 이름 규칙(`gtx_a_transport_card_YYYYMMDD_…csv`)으로 넣는다. 그다음 `config.py`의 `RAW_PATHS`에 추가한다.
- **새 공간자료/통계**: `raw/<자료이름>_<기준연도>/` 폴더를 새로 만든다 (예: `raw/landprice_2024/`).
- **다른 사람이 만든 중간 결과물**: `processed/`에 넣고, 이 표에 출처를 한 줄 적는다.
- 데이터 생성·병합 결과 CSV는 `processed/`에 저장한다.
- 지도·회귀표·보고서 같은 분석 결과물은 프로젝트 루트의 `outputs/`에 저장한다.
