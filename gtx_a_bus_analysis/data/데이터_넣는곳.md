# data/ — 데이터 넣는 곳

## GitHub에서 최종모형만 실행하는 경우

최종 Poisson QMLE와 음이항 NB2 노트북에 필요한 공개 가능한 집계자료는 저장소에 포함되어 있다.

- `processed/cell_route_all_day.csv`: 셀×노선별 2024·2025 종일 승차인원
- `../1_받은코드_정리/output/model_dataset.csv`: 격자별 분석 변수
- `../1_받은코드_정리/output/x_competing_destination_share_all_day.csv`: 2024년 종일 GTX 경쟁 목적지 비율
- `received_features/`: GTX 보행시간, IC 도로거리, 공급구조 유지 셀

따라서 `2_추가분석/11-1`, `11-2`, `11-3`은 원시 교통카드 자료 없이 실행할 수 있다.

아래 원자료 배치는 전처리 과정 전체를 처음부터 다시 수행할 때만 필요하다.

이 폴더의 파일은 용량이 커서(약 370MB) **전달용 zip에는 빠져 있다.**
아래 표대로 파일을 넣으면 노트북이 그대로 돌아간다. 경로는 `../config.py`에 정의되어 있다.

## 새 데이터가 생기면

- **교통카드 날짜 추가**: `raw/transport_card/`에 같은 이름 규칙(`gtx_a_transport_card_YYYYMMDD_…csv`)으로 넣는다. 그다음 `config.py`의 `RAW_PATHS`에 추가한다.
- **새 공간자료/통계**: `raw/<자료이름>_<기준연도>/` 폴더를 새로 만든다 (예: `raw/landprice_2024/`).
- **다른 사람이 만든 중간 결과물**: `received_features/`에 넣고, 이 표에 출처를 한 줄 적는다.
- 가공한 결과는 `data/`가 아니라 각 분석 폴더의 `output/`에 저장한다.
